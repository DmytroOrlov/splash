# Source fingerprint method

From the repository root run `python3 specs/003-upstream-battery-parity/evidence/final-20261113/manifest-method.py OUTPUT`. The script obtains the union of tracked (including staged) and unignored untracked paths via read-only `git ls-files --cached --others --exclude-standard`, selects files under runtime/, server/, install/, app/, and dev/ and root Makefile/build configuration names, and hashes actual filesystem bytes, sorted by filesystem-encoded path. Deleted paths are omitted. It excludes build and cache directories, installed model/profile/agent data, evidence, logs and bytecode. Root draft/ and vision/ assets, tasks.md and acceptance evidence are outside selection. Manifest SHA-256 hashes the complete manifest bytes, not Git blobs. Initial count: 704 files.
